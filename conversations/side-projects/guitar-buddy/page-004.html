Use a lowercase b, as in the example file:

Bbmaj7    x1323x
Am7b5     5x554x
D7b9      x5454x

GP8 draws these as proper flat symbols: B♭maj7, Am7♭5, D7♭9, as in your screenshot. # works the same way for sharps (D7#9 shows as D7♯9).

You can also type ♭ and ♯ directly. The tool converts them to b and # because GP5 files can't store those characters.

The chord name is free text, so there's no chord-spelling rule to follow. Just keep names to 22 characters or fewer and don't use spaces, because a space separates the name from the frets.

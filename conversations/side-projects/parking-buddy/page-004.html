The browser tests are hung, not slow. The cause was an incompatibility between our pinned Playwright 1.48.2 and Node 24, which is what CI's lts/* now installs. I've upgraded Playwright to fix it.

What I found: - The current run has been stuck on the browser-test step for over 75 minutes. Each was cancelled when you pushed the next commit (CI stops an in-progress run on a new push), so the browser job has never finished on CI. - With CI settings on Node 22 locally, all 11 tests pass in 17 seconds. On Node 24 the run hangs indefinitely with no output. - Even playwright test --list hangs on Node 24. So Playwright is stuck loading its config and test files, before it starts the web server or the browser.

The fix: I upgraded @playwright/test from 1.48.2 to 1.63.0 in package.json and package-lock.json. That's the newest release over a month old; 1.64.0 came out four days ago. All 11 tests now pass on both Node 24 and Node 22.

A safeguard: I added timeout-minutes to .github/workflows/ci.yml: 10 for the unit job, 15 for the browser job and 10 for the test step. A future hang will then fail within minutes instead of running up to GitHub's default 6-hour limit.
